# arafat.anam

Personal portfolio of Arafat Anam Chowdhury. Live at https://arafatanam.github.io/

One static page. No build step. GitHub Pages serves this repository from the `main` branch root.

## Files

| File                        | Purpose                                                         |
| --------------------------- | --------------------------------------------------------------- |
| `index.html`                | The whole site: markup, styles and scripts                      |
| `404.html`                  | Page shown for unknown URLs                                     |
| `favicon.ico`               | Icon for browsers that need a classic favicon                   |
| `favicon.svg`               | Sharp icon for modern browsers                                  |
| `apple-touch-icon.png`      | Icon when saved to a phone home screen                          |
| `og-image.png`              | Preview image for links shared on LinkedIn, WhatsApp and others |
| `robots.txt`, `sitemap.xml` | Search engine discovery                                         |
| `.nojekyll`                 | Tells GitHub Pages to serve files as they are                   |
| `portfolio-icons`           | All portfolio icons                                             |

## Add a project

In `index.html`, search for `ADD A PROJECT`. Copy one `<article class="row">` block and paste it first. Numbers update on their own.
